# Contributing to readme-stats-cards

Thanks for your interest in contributing! Here's how to get started.

## How to Contribute

1. **Fork** this repository
2. **Create a branch** for your feature or fix: `git checkout -b my-feature`
3. **Make your changes** and test them
4. **Commit** with a clear message: `git commit -m "feat: add new card type"`
5. **Push** to your fork: `git push origin my-feature`
6. **Open a Pull Request** against the `main` branch

## Reporting Bugs

- Open an [issue](https://github.com/Joydeep2005Banik/readme-stats-cards/issues) with:
  - A clear title and description
  - Steps to reproduce the problem
  - Your workflow YAML (with secrets redacted)
  - Any error messages from the Actions log

## Suggesting Features

- Open an issue with the `enhancement` label describing:
  - What you'd like to see
  - Why it would be useful
  - Any implementation ideas you have

## Code Style

- Keep YAML properly indented (2 spaces)
- Use meaningful commit messages following [Conventional Commits](https://www.conventionalcommits.org/)
